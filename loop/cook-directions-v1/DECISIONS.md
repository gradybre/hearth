# Implementation decisions

- D1: Split Claude author work into disjoint bounded outputs: pure formatter plus regression tests through the actual project controller; UI class snippets through its supported pinned no-tool subscription adapter. Astra integrates snippets and runs baseline-red tests before product source changes. Actual identities are retained in verification evidence. This avoids transmitting and regenerating the entire large cooking screen.
- D2: Enforce a full available reading width up to 560 points for the progress label and both short and long instructions. Loose width constraints would center short text despite left text alignment; Astra corrected the snippets before integration.
- D3: Paragraph formatting is presentation only. The original full instruction remains the speech/advance label and persisted recipe text. Ambiguous sentence boundaries remain unsplit. No automatic note classification or instruction rewriting.
- D4: Astra updates the old vertical-centering expectation in cook_along_test.dart to the approved top-anchored reading position. The first integrated run passed 99 tests and failed only this superseded design assertion; no behavior regression was waived.
- D5: The controller rejected the formatter author's JSON because it contained an unescaped control character and an oversized summary. After confirmed owner shutdown, Astra parsed that exact saved session with control-character tolerance, validated all three complete files and null base hashes, and mapped the helper/unit-test paths back into the assigned feature directory. The raw output and normalized bundle are preserved privately. No unreviewed file was applied automatically.
- D6: Astra's actual 320×568 at 3× capture with a running timer showed the fixed progress label left too little height for the full Mark done label. A new regression failed first. Focused progress now belongs to the same scrolling reading column; All steps keeps its original header. This preserves top alignment and frees enough room to read the full action after scrolling.
