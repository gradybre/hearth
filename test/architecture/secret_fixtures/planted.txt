Planted strings, one per rule in no_secrets_committed_test.dart.

None of these is real. They exist so the scanner can be shown to notice
something, because a scanner whose patterns have quietly stopped matching
passes exactly as loudly as one that found nothing — and this repository has
already been bitten twice by a test that could only pass.

Each is assembled to be obviously synthetic while still matching: the same
shape as the real thing, and a body that is plainly typed by a person.

The second line above carries no marker word on purpose: it is what a real one
would look like, and the scanner's own tests use it to show that a key without
a placeholder word in it is still caught. Both live here rather than in the
test file so that no key-shaped string is written in Dart source at all — a
formatter that folded two adjacent literals into one would otherwise make the
scanner start matching itself.

If a rule is added to the scanner, add a line here too — the test that reads
this file fails until every rule matches something, which is what stops a new
rule being written wrong and nobody finding out.
